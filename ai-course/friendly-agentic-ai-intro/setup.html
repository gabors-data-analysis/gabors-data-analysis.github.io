Friendly Introduction to Agentic AI for Social Scientists

Published

November 10, 2026

Part 1 of 4 · about an hour

Setup

Install the Claude desktop app, make a project folder, meet the agent, and let it set up Python for you

⌂ Overview 1 Setup 2 First steps 3 Staying in charge 4 A paper in 50 minutes

What do we do in this part?

Before a new research assistant can help, they need a desk, access to the right files, and the tools of the job. The agent is no different. In this part we install the app, make a folder for the agent to work in, have a first conversation with it, and let it install its own tools.

New here? Read the overview first: it explains what an agent is and what you need.

This part takes about an hour. The agent explains each step before it takes it, and you approve. If something fails, nothing is broken. See the troubleshooting table at the end, or ask the agent what went wrong.

NoteWhat you will have at the end

1.1 Install the Claude desktop app

  • Windows
  • Mac
  • Linux
  1. Download the installer: Claude for Windows. (On a Surface or other ARM laptop, use the ARM64 installer.)
  2. Run the downloaded file. If Windows shows a blue “Windows protected your PC” box, click More info → Run anyway.
  3. Open Claude from the Start menu and sign in with your Claude account.
  1. Download the installer: Claude for macOS. It works on Intel and Apple Silicon Macs.
  2. Open the downloaded .dmg file and drag Claude into Applications.
  3. Open Claude from Applications (or press Cmd+Space, type Claude) and sign in.

The desktop app for Linux is in beta, for Ubuntu and Debian. Follow the steps on the official page: Claude Desktop on Linux. Then start Claude from your application launcher and sign in.

On another distribution, use the terminal version of Claude Code: install guide. The rest of this course still applies. You type the same prompts in the terminal.

Then open the Code tab at the top of the left sidebar (hover over the icons if you see no names). If it asks you to upgrade, your plan doesn’t include Claude Code.

TipChat or Code?

The Chat tab is the chatbot you know. The Code tab is the agent. Don’t let the name mislead you: Code is for any work on files in a folder, text included.

1.2 Make a project folder

The agent works inside one folder. Think of it as the desk you give to a new research assistant: what is on the desk, they can read and work on. What is not, they can’t. Everything for a project lives there: data, code, notes, drafts, outputs. It is good practice to use a new folder for each project.

  1. In your Documents folder, create a folder called ai-projects, and inside it a folder called first-project.
  2. Use short names without spaces or accents (first-project, not My First Project (ÁÉ)). Programs handle plain names better.
  3. Show file extensions, so you can tell .md, .csv, .py and .docx files apart.
    • Windows: in File Explorer, click View → Show → File name extensions.
    • Mac: in Finder, open Finder → Settings → Advanced and tick Show all filename extensions.

Open the folder in Claude. In the Code tab, find the row of controls under the prompt box. Click the first one (the environment) and choose the top entry under Local. Then click the folder control next to it, choose Open folder… and pick first-project.

WarningWhat not to put in the folder (yet)

The agent sends what it reads to Anthropic’s servers. So keep confidential material out of the folder until you have checked your data agreement: interview recordings and transcripts, identifiable survey data, health records, anything under a data-use agreement, other people’s unpublished work. Also check your Claude account’s privacy settings, which control whether your conversations may be used to train future models. For learning, public data and your own drafts are fine.

1.3 Have a first conversation with the agent

Set the permission mode (in the row under the prompt box) to Manual. The agent then asks before it creates or changes any file and before it runs anything. True, this is slower. But you see everything, and that is what we want at the start. We advise staying in Manual for your first week.

Type this and press Enter:

Hi. I am new to this. What can you see in this folder? Then create a file called hello.md with three sentences about what you can do for a social scientist.

The agent looks at the folder (it is empty), then asks to create a file. Read what it wants to do. If it is unclear, click no and ask: “What does this do? Explain in one sentence.”

Then try three things.

  • Click hello.md in the chat. It opens inside the app.
  • Ask: “Make it two sentences and less formal.” The agent edits the file, not just the chat.
  • Click the stop button to interrupt it. You can also type a correction while it works.

Note the second one. With a chatbot, you would get a new version in the conversation and copy it over. Here the file itself changed.

1.4 Let the agent set up Python

This is the most technical step of the course, and you don’t need to follow the details. It takes five to ten minutes. Read the one-sentence explanation before each command, then approve.

Why Python, if you work with text? The agent uses small Python programs as its tools: to read Word and PDF files, to convert formats, to handle large datasets and to draw charts. Python is free, it runs on every computer, and AI models write it well. You won’t write any of it yourself.

Copy this prompt into the agent:

I have never used Python. Please set up Python for this project folder.

- Use uv (a modern Python installer) to install Python and create an environment for this project only. Do not change anything else on my computer without asking.
- Before each command, tell me in one sentence what it does.
- Install these packages: pandas, matplotlib, openpyxl, pyreadstat, pymupdf, python-docx, pypandoc-binary, requests.
- Test it: write a short script code/00_test.py that makes a simple bar chart of five made-up numbers and saves it as output/test_chart.png. Run it.
- Finally write docs/SETUP-NOTES.md: what you installed, where it lives, how to run a script, and how to undo all of it.

What do the packages do? pandas handles data tables, matplotlib draws charts, openpyxl reads Excel, pyreadstat reads Stata and SPSS files, pymupdf reads PDFs, python-docx reads and edits Word files, pypandoc-binary converts between Markdown and Word, and requests downloads data from the web.

It worked if output/test_chart.png shows a bar chart. Keep docs/SETUP-NOTES.md: when something breaks months later, show it to the agent first.

Already use Stata or R? Keep using them. The agent can write and run do-files and R scripts, too. For this course, Python is the path.

TipIf something goes wrong here (click to open)
  • Windows: if the agent says it needs Git, install Git for Windows with the default options, restart the Claude app, and ask the agent to continue.
  • Mac: a window may ask to install command line developer tools. Click Install, wait a few minutes, then tell the agent to continue.
  • “Command not found” right after an install: quit the Claude app fully and open it again.
  • In every case, paste the error into the chat and ask: “What went wrong? Explain simply, then fix it.”

1.5 Install a Markdown reader: Typora

The agent writes its notes, memos and plans in Markdown: plain text files ending in .md, where a few symbols do the formatting (# Title for a heading, **word** for bold, - item for a list). Agents read and write it very well, and the files open on any computer.

To read Markdown as formatted text, install Typora. It looks and edits like Word, runs on Windows, Mac and Linux, and costs about $15 once, after a free trial.

  1. Download and install Typora from typora.io.
  2. Open hello.md from Step 1.3 in Typora (right-click the file → Open with → Typora). It should look like a formatted document.
  3. Make Typora the default program for .md files, so a double-click opens it.
NoteIf you write code, or plan to

Use VS Code instead (free). It previews Markdown and also shows the agent’s Python, R or Stata code. The main course uses it.

Troubleshooting

Problem What to do
The Code tab asks me to upgrade Claude Code needs a Pro plan or higher. A free account only has Chat
The Code tab shows a sign-in prompt or a 403 error Finish the sign-in in the browser, then quit and restart the app. Still failing: see the official troubleshooting
The agent can’t see my files Check the folder control under the prompt box: is the right folder open?
Python, Git or a package “not found” after installing Quit the Claude app fully and start it again
An error I don’t understand Paste it in and ask: “Explain this error simply, then fix it.” This works more often than you would expect
