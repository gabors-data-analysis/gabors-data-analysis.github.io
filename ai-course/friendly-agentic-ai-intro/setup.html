Part 1 — Setup

Install the Claude desktop app, make a project folder, meet the agent, and let it set up Python for you

Before you start

This is Part 1 of the mini course Friendly Introduction to Agentic AI for Social Scientists. If you have not yet read the course page, start there: it explains what an AI agent is and what you need (mainly a paid Claude plan).

Part 1 takes about an hour. If something fails, nothing is broken. Read the troubleshooting section at the end, or simply ask the agent what went wrong.

NoteWhat you will have at the end of Part 1

Step 1.1 — Install the Claude desktop app

  • Windows
  • Mac
  • Linux
  1. Download the installer: Claude for Windows. (On a Surface or other ARM laptop, use the ARM64 installer.)
  2. Run the downloaded file. If Windows shows a blue “Windows protected your PC” box, click More info → Run anyway.
  3. Open Claude from the Start menu and sign in with your Claude account.
  1. Download the installer: Claude for macOS. It works on both Intel and Apple Silicon Macs.
  2. Open the downloaded .dmg file and drag Claude into Applications.
  3. Open Claude from Applications (or press Cmd+Space, type Claude) and sign in.

The desktop app for Linux is in beta, for Ubuntu and Debian. Follow the install steps on the official page: Claude Desktop on Linux. Then start Claude from your application launcher and sign in.

On another distribution, use the terminal version of Claude Code: install guide. Everything on this page still applies; you type the same prompts in the terminal.

Then open the Code tab. At the top of the left sidebar you see tabs such as Chat and Code. Click Code. (If you see only icons, hover over them to read their names.) If it asks you to upgrade, your plan does not include Claude Code yet.

Tip

The Chat tab is the chatbot you know. The Code tab is the agent. Despite the name, it is not only for programmers. It is the tab for any work on files in a folder, including text.

Step 1.2 — Make a project folder

The agent works inside one folder at a time. Everything for a project lives there: data, code, notes, drafts, outputs. It is good practice to start a new folder for each project.

  1. In your Documents folder, create a folder called ai-projects, and inside it a folder called first-project.
  2. Keep folder and file names short, without spaces or accents (first-project, not My First Project (ÁÉ)). Programs handle plain names better.
  3. Make file extensions visible. You will see files ending in .md, .csv, .py and .docx, and it helps to know which is which.
    • Windows: in File Explorer, click View → Show → File name extensions.
    • Mac: in Finder, open Finder → Settings → Advanced and tick Show all filename extensions.

Open the folder in Claude. In the Code tab, look at the row of controls under the prompt box. Click the first control (the environment) and choose the top entry under Local. Then click the folder control next to it, choose Open folder… and pick first-project.

WarningWhat not to put in the folder (yet)

The agent sends what it reads to Anthropic’s servers to process it. Do not put confidential material (identifiable survey responses, health records, anything under a data-use agreement, unpublished work of others) in a project folder until you have checked your data agreement. Also check the privacy settings of your Claude account, which say whether your conversations may be used to improve future models. For learning, public data and your own drafts are fine.

Step 1.3 — Your first conversation with the agent

Find the permission mode control in the row under the prompt box and set it to Manual. In Manual mode the agent asks before it creates or changes any file and before it runs anything. It is slower, but you see exactly what it does. Stay in Manual for your first week.

Now type this into the prompt box and press Enter:

Hi. I am new to this. What can you see in this folder? Then create a file called hello.md with three sentences about what you can do for a social scientist.

Watch what happens. The agent looks at the folder (it is empty), then asks permission to create a file. When it asks, read what it wants to do. If you do not understand it, click no and ask: “What does this do? Explain in one sentence.”

A few more things to try now:

  • Click the file name hello.md in the chat. It opens in a pane inside the app.
  • Type a follow-up: “Make it two sentences and less formal.” Note that the agent edits the file. It does not just answer in chat.
  • To stop the agent in the middle of something, click the stop button. You can also type a correction while it works.

Step 1.4 — Let the agent set up Python

This is the most technical step, and you do not have to understand it. It usually takes five to ten minutes, and your part is mostly reading and clicking Yes.

Why Python at all, if you want to work with text? Because the agent uses small Python programs as its tools: to read Word and PDF files properly, to convert between formats, to handle a dataset of any size, to draw charts. It is free, works on every computer, and AI models write it very well.

Copy this prompt into the agent:

I have never used Python. Please set up Python for this project folder.

- Use uv (a modern Python installer) to install Python and create an
  environment for this project only. Do not change anything else on my
  computer without asking.
- Before each command, tell me in one sentence what it does.
- Install these packages: pandas, matplotlib, openpyxl, pyreadstat,
  pymupdf, python-docx, pypandoc-binary, requests.
- Test it: write a short script code/00_test.py that makes a simple bar chart
  of five made-up numbers and saves it as output/test_chart.png. Run it.
- Finally write docs/SETUP-NOTES.md: what you installed, where it lives,
  how to run a script, and how to undo all of it.

What the packages are for, in one line each: pandas works with data tables, matplotlib draws charts, openpyxl reads Excel files, pyreadstat reads Stata and SPSS files, pymupdf reads PDFs, python-docx reads and edits Word files, pypandoc-binary converts between Markdown and Word, requests downloads data from the web.

When it worked: you can open output/test_chart.png and see a bar chart. Keep SETUP-NOTES.md. When something breaks in three months, that file is the first thing to show the agent.

Already working in Stata or R? Keep using them for your own analysis. The agent can write and run Stata do-files and R scripts too, if you ask it to. For everything on this page, Python is the path.

TipIf something goes wrong here (click to open)
  • Windows: if the agent reports that it needs Git, install Git for Windows with all default options, close and reopen the Claude app, and ask the agent to continue.
  • Mac: a window may pop up asking to install command line developer tools. Click Install. It takes a few minutes. Then tell the agent to continue.
  • “Command not found” right after installing: close the Claude app fully and open it again. New programs are often only found after a restart.
  • In every case, paste the error message into the chat and ask: “What went wrong? Explain simply, then fix it.”

Step 1.5 — A Markdown reader: Typora

The agent writes its notes, memos and plans in Markdown: plain text files ending in .md. A few symbols do the formatting: # Title makes a heading, **word** makes bold, - item makes a list. Markdown is the native language of AI tools. The agent reads and writes it perfectly, and the files open on any computer, forever.

In a plain text editor you see the symbols. To read Markdown comfortably, install Typora. It shows the formatted text, the way Word does, and you can edit it the same way. It runs on Windows, Mac and Linux. It costs about $15 once, after a free trial.

  1. Download and install Typora from typora.io.
  2. Open your hello.md from Step 1.3 in Typora (right-click the file → Open with → Typora). It should look like a normal formatted document.
  3. Make Typora the default program for .md files, so a double-click opens it.
Note

If you write code, or plan to, use VS Code instead (free). It shows Markdown with a preview, and it is also where you read the agent’s Python, R or Stata code. We use it in the main course.
